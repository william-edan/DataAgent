# 员工档案查询快速参考

## 🎯 核心规则

**查询"员工档案"时，必须关联两个表**：

```sql
FROM oa_admin a
LEFT JOIN oa_admin_profiles p ON a.id = p.admin_id
```

## 📊 表说明

| 表名 | 用途 | 关联键 |
|------|------|--------|
| oa_admin | 员工基本信息（部门、岗位、状态） | id |
| oa_admin_profiles | 员工档案详情（教育、工作、证书） | admin_id |

**关系**: 一对多（一个员工有多条档案记录）

## 💡 关键词触发

这些关键词出现时使用 LEFT JOIN：
- 档案、档案信息、完整档案
- 详细资料、完整信息、履历
- 教育经历、工作经历、证书

## 📝 标准模板

```sql
SELECT
  a.id, a.name, a.did, a.position_name, a.position_rank,
  a.type, a.is_staff, a.age,
  p.types, p.title, p.speciality, p.education,
  p.start_time, p.end_time, p.remark
FROM oa_admin a
LEFT JOIN oa_admin_profiles p ON a.id = p.admin_id
WHERE a.name = ?
ORDER BY p.types, p.start_time DESC;
```

## 🏷️ 档案类型

`p.types` 字段：
- 1 = 教育经历
- 2 = 工作经历
- 3 = 相关证书
- 4 = 计算机技能
- 5 = 语言能力
